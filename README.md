

# Caesar Cipher

A Caesar cipher that encrypts and decrypts messages by shifting each letter by a number from 1 to 25. Spaces, numbers and punctuation stay unchanged.

## Files
- `caesar.py`: my original Python version, written while learning Python basics
- `index.html`: web version of the same cipher

## How it works
Each letter moves forward in the alphabet by the shift (decrypting moves it back), wrapping from Z to A. For example, with a shift of 3, `Hello` becomes `Khoor`.
